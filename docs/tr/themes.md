# Temalar

[Kılavuz](guide.md) · [Komutlar](commands.md) · [English](../en/themes.md)

Nord varsayılan kalır. 18 temanın her biri terminal renklerini, Powerlevel10k promptunu, önerileri ve sözdizimi renklendirmesini birlikte değiştirir.

```sh
gtterm theme list
gtterm theme dracula
gtterm theme tokyo-night
gtterm theme nord
```

`gtterm theme ` sonrasında Tab ile tema adını tamamlayın. Tema komutu mevcut oturumu değiştirir. Yeni pencere için **Profiles → gtterm - …** altından temanın tam profilini seçebilirsiniz. Kalıcı varsayılanı isterseniz iTerm ayarlarından değiştirin. gtterm oturumları yeniden başlatmaz veya macOS görünümünü değiştirmez.

| `nord` | Nord |

Tüm renkler ve profiller çevrimdışı kullanım için pakete dahildir. Sudo, Homebrew veya ek program gerekmez. Tema kaynakları ve sabitlenmiş sürümler `THEME-SOURCES.json` ve `themes/` içinde bulunur. README olduğu gibi korunmuştur.
