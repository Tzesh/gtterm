# Themes

[Guide](guide.md) · [Commands](commands.md) · [Türkçe](../tr/themes.md)

Nord remains the default. All 18 themes coordinate the terminal palette, Powerlevel10k prompt, suggestions and syntax highlighting.

```sh
gtterm theme list
gtterm theme dracula
gtterm theme tokyo-night
gtterm theme nord
```

Use Tab after `gtterm theme ` to complete a name. Theme changes affect the current session. Each theme also has a full iTerm profile under **Profiles → gtterm - …**; choose a profile when opening a new window. Change the default from iTerm settings if desired. gtterm does not restart sessions or change macOS appearance.
